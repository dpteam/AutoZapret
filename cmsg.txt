feat(P2): domain import by drag-and-drop, danger confirms, simple mode, speed meter

Four items that were listed as 'setting exists but the UI ignores it' or
were missing outright.

1. Import domains from a file: a button and drag-and-drop straight into
   the textarea. The file is read in the browser via FileReader, so no
   native open dialog and no path crossing the bridge - only text, which
   is what 'Save' takes anyway. The same code will work on Android, where
   there is no Windows dialog at all.
   Import APPENDS instead of replacing: dropping the wrong file and
   silently losing your list is too easy a mistake to design in.
   Notepad BOM and CRLF are stripped, 4 MB cap, empty file reported.

2. Confirmation on irreversible actions. The text names the consequence,
   not 'are you sure?': hosts restore says entries added since the backup
   will disappear; a new proxy secret says every distributed link stops
   working. Applied to hosts apply/restore, local-subnet rewrite, list
   extension, and secret regeneration.

3. Simple mode now actually does something. body.simple plus a
   data-advanced attribute next to each element, hidden by one CSS rule.
   Hiding the attribute next to its element means the list of hidden
   things cannot drift out of sync with the markup. Hidden: engine
   selector, ipset mode, update channel, process presets, hosts, fakes.
   The switch toggles instantly instead of waiting for a save round-trip.

4. Traffic speed on the home screen. NetStats diffs interface counters
   once a second, and only while home is open - no point pushing bridge
   messages from a screen nobody is looking at. Labelled honestly as
   whole-machine traffic: per-process byte counts need ETW, and WinDivert
   works in the kernel, so 'bypass speed' cannot be measured this way.
   Loopback and tunnels are excluded; a counter reset yields 0 rather
   than a negative rate.

selftest: 14 checks on NetStats - formatting at every unit boundary,
rate arithmetic, counter reset, too-short interval, null inputs, and a
live Sample(). The formatting checks build the expected string from
CurrentCulture on purpose: Russian Windows prints '1,0' and English
prints '1.0', and the test must not depend on the machine.
