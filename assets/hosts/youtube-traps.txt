### YouTube - ловушки российских кэшей (замедление видео)
#
# РКН подменил кэширующие серверы YouTube, которые стоят в России:
# имена остались прежними, а отдают они медленно или не отдают вовсе.
# Браузер берёт сервер из списка, который вернул YouTube, попадает на
# ловушку - и видео висит, хотя страница и картинки открываются.
#
# Список привязывает 147 известных имён-ловушек к 0.0.0.0, то есть
# в никуда. Тогда YouTube выбирает следующий сервер из своего списка,
# и если с зарубежными соединение работает - видео идёт.
#
# ЭТО НЕ ЛЕЧИТ ВСЁ. Если с зарубежными серверами связи нет, поможет
# только VPN или WARP: блокировка ловушек не создаёт маршрут там,
# где его нет.
#
# Почему имён так много: ловушки у каждого провайдера свои, а списки
# собирали разные люди (Дом.ру, Мегафон, МТС). Здесь объединение:
# лишнее имя, которого у вашего провайдера нет, ни на что не влияет -
# оно и так не резолвится.
#
# Чего здесь НЕТ:
#
#   * 70 имён, которые ведут на РАБОЧИЕ зарубежные серверы
#     Google (Германия, Польша, Швейцария). Записи в hosts не ускоряют
#     YouTube - они убирают имя из выбора. Убрать хороший сервер значит
#     оставить клиенту только ловушки;
#   * ещё 8 имён из того же разряда (Брюссель, Торонто,
#     Маунтин-Вью) - их проверили отдельно, адреса в генераторе;
#   * 3 имени, которые при проверке не заресолвились: догадка
#     «наверное тоже не в России» - не основание блокировать;
#   * 27 имён, которых не существует. Авторы списков дописали
#     rr1..rr10 «на всякий случай», хотя у тех семейств есть только rr1..rr5.
#     Проверено резолвом каждого номера от rr1 до rr12.
#
# Если стало хуже - снимите галочку и сохраните hosts.
#
# Источник: github.com/Flowseal/zapret-discord-youtube/issues/18271
# Сгенерировано: tools/gen-youtube-traps.js
#
# Перезапустите браузер после применения: он держит DNS в своём кэше.
