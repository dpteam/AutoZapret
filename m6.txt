fix: preflight blocked every strategy with an inline domain list

The user's log: "Blocker: нет файла списка доменов — discord.media" for
ALT12, start cancelled. That was my bug from the previous commit, and a
nasty one: it blocked strategies for everyone.

zapret has two different things with similar names:
  --hostlist=<file>              a path to a file
  --hostlist-domains=<domains>   inline domains, no file at all
The preflight matched by the "--hostlist" prefix, so "discord.media" was
treated as a missing file. Now only the exact file-taking options are
checked: --hostlist, --hostlist-exclude, --ipset, --ipset-exclude.
Confirmed against both strategy sets: those four plus --dpi-desync-fake-*
(already covered by the .bin suffix) are the only file-valued options.

The regression test is the interesting part: selftest now runs preflight
across all 44 strategies and fails if any of them reports a missing
hostlist. A single-strategy test would have missed this; the check has to
cover the whole catalogue because that is where the variation lives.
