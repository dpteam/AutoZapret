# AutoZapret

**Один инструмент для обхода блокировок на Windows: zapret + Telegram-прокси в одном окне.**

Никаких `.bat`-файлов, никаких консольных окон, никакой ручной правки конфигов.
Включил — работает. Свернул в трей — работает. Закрыл — выключилось.

> ⚠️ **Это не VPN.** AutoZapret не меняет ваш IP и не шифрует трафик. Он мешает
> оборудованию провайдера распознавать соединения (DPI) — тем же способом, что и
> [zapret](https://github.com/bol-van/zapret). Против блокировок по IP-адресу он не поможет.

## Что умеет

| | |
|---|---|
| 🚀 **Обход DPI в один клик** | 60+ готовых стратегий: Discord, YouTube, Google, игры, «всё подряд» |
| 🎯 **Автоподбор** | Сам перебирает стратегии, замеряет что реально открывается, выбирает рабочую |
| ✈️ **Telegram-прокси** | Встроенный MTProto-over-WebSocket прокси: Telegram работает без VPN |
| 🗂 **Списки** | Свои домены и исключения, автообновление ipset, hosts |
| 🔧 **Диагностика** | 12 проверок: почему не работает и что делать |
| 📌 **Трей** | Быстрое вкл/выкл, закрытие окна = сворачивание, выход только из трея |
| 🔄 **Обновления** | Движок и само приложение обновляются сами |

## Требования

- **Windows 10 (1607+) или Windows 11, x64**
- **.NET устанавливать не нужно** — рантайм вшит в exe
- **Microsoft Edge WebView2 Runtime** — есть в Windows 11; для Windows 10
  [скачать здесь](https://go.microsoft.com/fwlink/p/?LinkId=2124703)
- **Права администратора** — нужны драйверу WinDivert для перехвата пакетов

> Windows 7 и 8.1 больше не поддерживаются: .NET 9 работает только с Windows 10 1607 и новее.

## Быстрый старт

1. Скачать и распаковать архив в папку **без кириллицы и спецсимволов** в пути
   (например `C:\AutoZapret`).
2. Если скачивали через браузер — правый клик по архиву → **Свойства** → **Разблокировать**.
3. Запустить `AutoZapret.exe`, согласиться на UAC.
4. Нажать **▶ Включить обход**.
5. Проверить: открывается ли YouTube / работает ли Discord.

Если не работает — вкладка **Диагностика** → **Проверить всё**. Там будет написано,
что именно мешает.

## Антивирус и SmartScreen

**WinDivert** — это драйвер для перехвата и фильтрации трафика. Он нужен, чтобы
модифицировать пакеты до того, как их увидит DPI. Тот же драйвер используют легальные
файрволы и мониторы трафика.

Некоторые антивирусы относят его к «инструментам повышенного риска» и удаляют файл.
Детект всегда называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.

**Что делать:**
- Добавить папку с AutoZapret в исключения антивируса, **или**
- Отключить детектирование PUA (потенциально нежелательных приложений).

Если не понимаете, что делаете — не отключайте защиту целиком, добавьте исключение на папку.

SmartScreen может ругаться на неподписанный файл: **Подробнее** → **Выполнить в любом случае**.

## Как это работает

```
AutoZapret.exe  (GUI, трей, прокси)
      │
      ├── engine/winws.exe  ──►  WinDivert  ──►  сеть
      │      (стратегии обхода DPI)
      │
      └── встроенный Telegram-прокси  ──►  kws*.web.telegram.org
```

`winws.exe` перехватывает исходящие пакеты и «ломает» их так, чтобы DPI не смог
определить, к какому сайту вы идёте — но получатель собирает их обратно без потерь.
Стратегия — это набор правил: где разрезать пакет, чем «прикрыть» разрез, что подсунуть
вместо начала TLS-рукопожатия.

Разные провайдеры блокируют по-разному — поэтому стратегий много и есть автоподбор.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| Ничего не открывается после включения | Сменить стратегию. Запустить **Диагностика → Проверить всё** |
| Работает YouTube, но не Discord | Выбрать стратегию с меткой `Discord` |
| Работает, но через 10 минут перестало | Провайдер сменил фильтр. **Автоподбор** или другая стратегия |
| «Не удалось запустить winws» | Проверить, что антивирус не съел `WinDivert64.sys` |
| Сайты банков/госуслуг не открываются | Добавить их в **Списки → Исключения** |
| Telegram не подключается | Вкладка **Прокси** → включить → «Открыть в Telegram» |
| После удаления пропал интернет | Запустить `engine\windivert_delete.cmd` от админа и перезагрузиться |

## Windows 7

**Не поддерживается.** .NET 9 требует Windows 10 1607 или новее.

Если нужна работа на старой системе — используйте оригинальный
[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
напрямую через `.bat`-файлы.

На Windows 8/10 может потребоваться **отключить Secure Boot** — WinDivert подписан,
но политика Secure Boot иногда мешает загрузке драйвера.
