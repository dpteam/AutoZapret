Шаг 0 — проверки окружения
14 проверок системы
BFE, драйвер, timestamps, конфликтующие обходчики, VPN, антивирус… · ~10 s
Зашифрованный DNS в браузерах
Провайдер подменяет DNS — браузер приходит на заглушку, и сайт не открывается даже при рабочем обходе. Включает Secure DNS (DoH) в Chrome, Edge, Яндекс, Firefox и родственных. Обратимо
Системный DNS через DoH (все программы)
В Windows 10 своего DoH нет. Включаем локальный резолвер на 127.0.0.1, который ходит в DoH, и переключаем на него адаптер с интернетом — так Discord, игры и Telegram перестают попадать на заглушку 198.18.x. Обратимо: «Вернуть» восстанавливает прежние серверы
Сбросить кэш DNS
Windows держит ответы в кэше: после правки hosts или смены DNS старые адреса продолжают работать. Сбрасывается автоматически при записи hosts и при включении системного DNS — эта кнопка на всякий случай
Архив для поддержки
Логи, настройки, версии и проверки в одном ZIP. Секрет прокси вырезан · ~2 s
Шаг 1 — что заблокировано
Проверить сеть без обхода
Обход должен быть выключен — иначе замер врёт · ~20–40 s
Шаг 1б — видит ли драйвер трафик
Сниффер WinDivert
Слушает TCP/443 и показывает, что реально проходит мимо DPI. Если здесь пусто — стратегии не помогут · 8 s
Шаг 2 — почему не открывается
Определить тип блокировки

Шаг 2б — обрыв по объёму (16-20 КБ)
Проверить обрыв на 16-20 КБ
Сайт открывается и висит? Провайдер рвёт поток после ~16 КБ. Лечится seqovl-стратегиями · ~20–30 s
Шаг 3 — подобрать стратегию
Перебрать стратегии

Свой движок: подбор техники


        

          

            
Техника desync

            

              Перехват TCP/443 своим кодом, без winws. Выключите обход выше —
              два перехватчика одновременно не работают. Для постоянной работы
              выберите «свой движок» в списке движков, а здесь — подбор техники
            

          

          
        


        

          

            
Параметры

            
Позиция разреза, повторы фейка, перекрытие (seqovl), секунды работы

          

          

            
            
            
            
          

        


        

          

            
Fooling

            

              Как заставить DPI выбросить фейк, а получателя — не принять его.
              Работает только с техниками fake и fakedsplit

              Выбранная стратегия отменяет настройки техники выше — это те же
              правила, другой исполнитель
            

          

          
        


        

          

            
Только показать

            
Ничего не отправлять: увидеть, что было бы сделано

          

          

        


        

          

            
Только свои цели

            

              Брать списки движка (домены и подсети), как winws. Без этого движок
              трогает весь TCP/443 — включая банки. Для постоянной работы включайте
            

          

          

        


        

          

            
Профили, как у zapret

            

              Отдельная техника для Google и Discord, выбранная выше — для остального.
              То, что пробивает Google, не обязано пробивать Discord. Работает только
              вместе с «Только свои цели»
